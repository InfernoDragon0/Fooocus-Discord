# Meowy Fooocus

A Discord bot for a self-hosted [Fooocus](https://github.com/lllyasviel/Fooocus) server. Streams generation previews into Discord messages.

![image](https://raw.githubusercontent.com/InfernoDragon0/Fooocus-Discord/refs/heads/master/samples/sample1.png)

## Features

- `/imagine` text-to-image with model, styles, aspect ratio, performance, seed, LoRA, guidance and sharpness options (autocomplete for models, styles, LoRAs and aspect ratios).
- `/blend` with up to four reference images as Image Prompt, FaceSwap, PyraCanny or CPDS.
- `/inpaint` edits the part of an image you describe in words ("the hat", "background"). Generated by Fooocus SAM + GroundingDINO.
- `/describe` turns an image into a prompt, with an "Imagine this" button.
- `/queue`, `/cancel`, `/models`.
- Buttons: U1-U4 (pick from a grid), Vary (Subtle/Strong), Upscale 1.5x/2x, Zoom Out, pan arrows, Reroll, Cancel.
- FIFO queue with one worker, one pending job per user, live position updates and streamed preview frames.
- Optional: starts Fooocus itself, applies an NVIDIA power limit while running (restored on exit), and shows a tray icon with Open UI / Open outputs / Exit.

## Requirements

- Windows (if you want the tray icon and power limit via nvidia-smi. if not, works with Linux and Macos)
- Node.js 22+.
- Fooocus 2.5.x portable install (Gradio 3.41). The bot launches `Fooocus\launch.py` directly.
- A Discord application with a bot token. Invite it with the `applications.commands` and `bot` scopes.

## Setup

Create your own discord app via developer portal:

1. Developer Portal > Applications > New Application
2. Select your application > **Installation**: enable **User Install** & **Guild Install**, set the install link to "Discord Provided", and give the user-install scope `applications.commands`.
   1. User install if you want the app to be used in DMs or user chats: `Share the install link from that page. Users  choose "Add to My Apps" and can then run /imagine in DMs, group DMs and any server.`
   2. Guild install if you want the app to be used in servers

```
npm install
copy .env.example .env          # fill in DISCORD_TOKEN, CLIENT_ID and optionally GUILD_ID
copy config.example.json config.json
```

Edit `config.json`:

| key                                                                                     | meaning                                                                                                             |
| --------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `fooocus.baseUrl`                                                                     | Where Fooocus listens (`http://127.0.0.1:7865` by default)                                                        |
| `fooocus.autoStart`                                                                   | Start Fooocus if nothing answers at`baseUrl`                                                                      |
| `fooocus.installDir` / `pythonExe` / `launchScript`                               | The portable install;`run.bat` is not used                                                                        |
| `fooocus.preset`                                                                      | `anime`, `realistic`, … or `null` for the default preset                                                     |
| `fooocus.extraArgs`                                                                   | Extra Fooocus CLI flags (never add`--disable-image-log`)                                                          |
| `fooocus.outputsDir`                                                                  | Folder opened by the tray menu                                                                                      |
| `queue.maxPendingPerUser` / `maxQueueSize`                                          | Queue limits                                                                                                        |
| `generation.defaultCount` / `maxCount` / `defaultPerformance` / `allowedModels` | Generation defaults;`allowedModels` restricts the checkpoints users may pick                                      |
| `generation.defaultStyles`                                                            | Styles applied when the user gives none:`[]` for none, `null` for the Fooocus preset styles, or a list of names |
| `generation.presetLoras`                                                              | `false` disables the LoRAs the Fooocus preset loads by default; a `lora` option still applies                   |
| `discord.progressEditIntervalMs`                                                      | How often the progress message is edited (min 1000)<br />                                                           |
| `discord.maxUploadBytes`                                                              | Upload cap; larger PNGs are re-encoded to JPEG for Discord                                                          |
| `gpu.powerLimitWatts`                                                                 | NVIDIA power limit while the bot runs, or`null`                                                                   |
| `gpu.method`                                                                          | `nvidia-smi` (bot relaunches itself elevated via UAC) or `scheduled-task` (see below)                           |
| `gpu.elevate`                                                                         | `auto` or `never`                                                                                               |
| `tray.enabled`                                                                        | Tray icon on/off                                                                                                    |
| `log.level`                                                                           | `trace` … `error`                                                                                              |

Register commands with ``npm run deploy`` or ``npm run deploy -- --global``

Run with ``npm run dev``

If `gpu.powerLimitWatts` is set, the bot requires admin permissions (UAC)

`npm run dump-config` prints the Fooocus endpoints and control positions the bot resolved

## GPU power limit without UAC prompts

`nvidia-smi -pl` needs administrator rights. If you prefer not to run the bot elevated, create two scheduled tasks once (from an elevated PowerShell):

```
powershell -ExecutionPolicy Bypass -File scripts\install-gpu-tasks.ps1 -LimitWatts 250
```

Then set `"gpu": { "powerLimitWatts": 250, "method": "scheduled-task" }`. The bot triggers the tasks with `schtasks /Run`, which does not need elevation. Set 250 to whichever power limit you are comfortable with.

## Notes

- First use of `/blend`, `/inpaint` and some performance modes makes Fooocus download models (you can pre download by warming up via browser yourself). The timeout is `fooocus.idleTimeoutSec`.
- Generated files stay in Fooocus outputs folder and the bot has an extra copy at `data/images` so buttons keep working after Fooocus restarts.
